# Таблички с заданиями по электронным таблицам

Таблички предназначены для заданий по работе с Excel в формате ОГЭ по информатике. Условия, файлы таблиц и правила проверки конкретных ответов будут добавлены сюда отдельно. Сейчас окно показывает заглушку и кнопку закрытия.

| Сложность | Золотые монеты за верное решение |
| --- | ---: |
| Базовая (по умолчанию) | 20 |
| Средняя | 40 |
| Повышенная | 70 |

На деревьях встречаются базовые и средние задания. На траве доступны все три уровня. Уровень назначается при первом обнаружении и сохраняется вместе с клеткой. После проверки ответа интерфейс передаёт результат в `submitVerifiedAnswer(correct)` открытой таблички. Только верный ответ приносит награду и убирает табличку с карты. Открытие, закрытие, ошибочный ответ и повторная отправка верного ответа дают ноль монет. После смены суток ответ для вчерашней таблички утрачивает силу.
