# КУБ — браузерная игра

Локальная 3D-игра на Three.js (vendored 0.170.0), JavaScript и CSS. Сбор семи кубов, строительство арки по шаблону, шесть материалов, свободное строительство, два вида камеры, прыжки и столкновения.

Запуск из каталога проекта:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте страницу сервера в настольном браузере с WebGL. WASD — движение, мышь — обзор, V — камера, пробел — прыжок, 1–6 — материал, ЛКМ — собрать/поставить, ПКМ — убрать, Esc — освободить мышь. Для арки используйте золотистые кубы, разбросанные по острову. Остальные материалы неограниченны.

Сборка и ключи API не требуются. Three.js хранится локально; внешний шрифт необязателен, предусмотрен системный fallback. Сенсорное управление пока не реализовано.

Персонаж: 85 блочных деталей, двухзвенная анимация ног с расчётом коленей, направленные шаги вперёд/назад/вбок, плавная остановка, позы прыжка и приземления. Скорость шага зависит от реального перемещения после проверки столкновений. Модель и анимация находятся в `character.js`.

Проверка анимации и столкновений (Node.js 22+): `node --test tests/*.test.mjs`.

Столкновения с камнями, стволами и построенными блоками рассчитываются по трём осям в `physics.js`: можно запрыгивать на поверхности, стоять на них и спрыгивать. Повторный прыжок требует нового нажатия пробела; после схода с края опора теряется.
